# Automated Tests for [Test Task Manager](https://github.com/franciscatacutan/team-tesk-manager)

## Run Locally via VSCode
### Setup
#### Build docker image

Run task: `Docker Compose Up (Build)`

OR

Run command: `docker compose up -d --build`

### Run Tests
#### 1. Run tests under `Run and Debug` tab (Ctrl + Shift +D)
#### 2. An Allure report will be created
